## 🏛️ The 4 Ikigai Pillars of Arvaana

1. **Kenko (健康 — Vitality & Well-Being)**:
   - Elevated oxygen zones, biophilic flora, skyline yoga decks, and rooftop Himalayan salt sauna.
2. **Chowa (調和 — Harmonious Multi-Generational Balance)**:
   - Double-height family living pavilions, multi-generational acoustic buffers, zero-threshold flooring, and private domestic staff quarters.
3. **Yutakasa (豊かさ — Affluence & Rarity)**:
   - Low density of 2 homes per floor, 270-degree wraparound view decks, and private keycard access.
4. **Kizuna (絆 — Connection & Fellowship)**:
   - Private 24-seat Dolby Atmos Cinema, Starlight Observatory, Executive Boardroom, and Tasting Salon.

## 💻 Tech Architecture & Experience Features

- **Built with**: React 18, Vite, Tailwind CSS, Lucide Icons, Canvas Confetti.
- **Audio Synthesis**: Integrated Web Audio API Japanese Zen ambient sound generator with live tone synthesis.
- **3D Interactive Tower Navigator**: Floor-by-floor interactive elevation stack across all 33 levels.
- **Blueprint Configurator**: Room dimension inspector for 4 BHK, 4.5 BHK, and Duplex layouts with luxury material specifications.
- **360° Draggable Room Walkthrough**: Interactive panoramic simulator with orientation compass, auto-rotation, and glowing material inspection pins.
- **Statutory Cost Sheet & Mortgage Simulator**: Live calculation of Maharashtra Stamp Duty (7%), GST (5%), Registration, and dynamic EMI sliders.
- **Bespoke VIP Proposal & Dossier Generator**: Generates customized client certificates with confetti animations and one-click PDF printing.
- **Concierge Integration**: Direct WhatsApp and VIP site visit scheduler with chauffeured BMW pickup options.

## 🚀 Running the Project

```bash
# Install dependencies
npm install

# Start local development server
npm run dev

# Build production bundle
npm run build

# Preview production build
npm run preview
```

The application runs locally on `http://localhost:3000/`.
